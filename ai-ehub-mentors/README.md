# AI EHub Mentor Tools

For mentors only: Session Planner.

Mentors: first add the main AI EHub marketplace (github.com/ai-ehub/ai-ehub) for the 16 area tools, then add this one for Session Planner.

To add in Claude: Customize > Plugins > Add > Add marketplace, then enter this repository's address and install Mentor Tools. Turn on Sync automatically to receive updates.

**AI EHub Launcher:** https://claude.ai/artifact/51tYU7RsF8zUkDKzwxgNCv
One page listing every tool, when to use it, and a Copy button for its starter sentence. Paste it into a new Claude chat, add your details, and send.
