# Mentor Tools — AI EHub (Mentors Only)

Tools for mentors, not for mentees. Share this plugin only with other mentors.

| Tool | Use for | Try this prompt |
|---|---|---|
| **Session Planner** | Plan mentoring sessions | "Use Session Planner. Prepare for a [first/follow-on] mentoring session using these notes and client goals: [details]." |

## What Session Planner does

- Opens every plan with **Confirmed Inputs**, **Missing Inputs**, and **Assumptions to Validate**, and only stops to ask when something material is missing.
- Merges a Zoom summary with a chat transcript, flagging conflicts and keeping estimates labeled as estimates.
- Builds **For Mentor**, **For Mentee**, and **Shared Session Agenda** sections.
- Recommends one AI EHub tool for the central problem (two at most), each with a copy-ready prompt that starts "Use [tool name]."
- Delivers the finished plan as a Word document in Helvetica, ready to open in Pages. Code execution / file creation needs to be turned on in Claude for this; otherwise the plan is given in chat.
- Works on one mentee per chat and flags notes that seem to mix clients.

Attach session notes or transcripts directly to the chat. Turn on web search for first sessions that need current industry facts.
